# Specifications

This directory contains durable design records, implementation contracts, and the active improvement roadmap for the documentation repository. Published clinical safety and regulatory records under `docs/safety/` remain authoritative where a specification overlaps them.

## Reading Order

1. [Site Specification](spec.md) - purpose, audiences, information architecture, and site expectations.
2. [Growth-Reference Provenance Contract](growth-reference-provenance-contract.md) - API provenance response and persistence contract.
3. [Five-Repository Upgrade Runbook Specification](five-repository-upgrade-runbook.md) - design record for coordinated platform upgrades.
4. [Roadmap](roadmap.md) - active documentation improvements and deferred house-style work.
5. [Style Guide](style-guide.md) - historical visual and content guidance; prefer current Zensical configuration and contributor documentation where they differ.

`qms.md` is a draft that is not the controlled quality manual. The authoritative Quality Management System is [`docs/safety/qms.md`](../docs/safety/qms.md). Do not implement or cite conflicting claims from the draft without resolving them through clinical and quality-management review.
