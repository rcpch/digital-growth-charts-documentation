# Chart Component Storybook

[Storybook](https://storybook.js.org/) is interactive documentation for the [RCPCH Digital Growth Charts React Component Library](https://github.com/rcpch/digital-growth-charts-react-component-library). It documents every prop the `<RCPCHChart>` component accepts, the supported themes, and includes a live Theme Builder for generating custom style props.
